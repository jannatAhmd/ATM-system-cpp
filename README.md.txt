# ATM System (C++)

Console ATM application built as a course project (Dr. Mohammed Abu-Hadhoud's Algorithms and problem solving level 4 course). Individual project.

## Features
- **Login:** username and PIN screen at startup
- **Quick withdraw**
- **Normal withdraw**
- **Deposit**
- **Check balance**
- **Log out**

## System rules
- Every input is validated before the transaction is applied
- Account data is saved in a .txt file, so balances stay between sessions

## Tech stack
C++, Visual Studio, file storage (.txt files)

## Sample data
The project includes a sample .txt file: Clients.txt.
Sample login: account number `A150`, PIN `1002` (sample account only, with fake data).

## How to run
1. Open PRO2 My sol.vcxproj in Visual Studio.
2. Make sure the .txt files are in the same folder as the project.
3. Press F5.

Building a menu-driven application with input validation and file storage.
